# Phase 4 - Error States and Edge Cases

Test edge cases:

- No contacts
- No leads
- No tasks
- No campaigns
- No workflows
- No staff
- No service orders
- Missing billing config
- Missing AI config
- Missing integrations
- Network/API error
- Permission denied
- Expired invite
- Offline connector if applicable
- Empty analytics

Every case should show a useful state, not crash or fake data.
