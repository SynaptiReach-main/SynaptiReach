# Phase 4 - Data Integrity, Error Handling, and Empty States

Audit all main flows for real data behavior.

Main flows:
- Landing/pricing/signup
- Onboarding
- User CRM
- Admin portal
- User staff portal
- Campaigns
- Workflows
- AI tools
- Billing/service orders
- Settings
- Integrations

Ensure:
- No fake records appear.
- Empty states are helpful.
- Error states are clear.
- Loading states are present.
- Failed queries do not crash entire pages.
- Missing optional integrations do not break core app.
- Users cannot access other organizations' records.
- Admin-only tools are protected.
- Destructive actions are confirmed.

Add small fixes only where needed.
