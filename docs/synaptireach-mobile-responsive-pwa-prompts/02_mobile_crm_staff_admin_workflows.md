# Phase 2 - Mobile CRM, Staff, and Admin Workflows

Optimize key mobile workflows:

User CRM:
- Add contact
- View lead
- Update opportunity
- Complete task
- Send follow-up
- Use AI assistant

User Staff:
- View assigned leads
- Complete tasks
- Add notes
- Review approvals
- Accept invite

Admin:
- Review alerts
- Approve/deny
- View user profile
- Check service order
- See system health

Use responsive action sheets, stacked cards, and mobile-friendly navigation where appropriate.
