## Integration-Ready Sources

Prepare for real integrations such as:

- Google Business Profile / Places API
- Search result APIs
- Public business websites
- Business directories where allowed
- Local chamber directories
- Public social profiles where allowed
- Technology detection APIs
- PageSpeed Insights
- SEO APIs
- Review APIs where permitted
- Manual CSV import
- Manual prospect entry

## Compliance Requirements

- Respect privacy laws.
- Respect platform terms.
- Respect anti-spam laws.
- Keep outreach status clear.
- Avoid unsafe automation that sends messages without approval.
- Require approval before launching outreach if sending integrations exist.

## Data Requirements

- Do not create fake prospects.
- Do not hardcode prospect examples.
- Use real data integrations when available.
- If integrations are not available, create the UI and service abstraction ready for real APIs.
- Manual prospect entry should be supported.
- CSV import should be supported if feasible.

## Deliverable

Deliver a real-data-ready Client Finder, prospect scoring interface, prospect detail page, outreach tools, staff assignment, and prospect-to-client conversion pipeline.
