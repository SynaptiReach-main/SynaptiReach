# Phase 10 - Templates, Knowledge Base, Reports, Integrations, and Audit Logs

Use the instructions from `00_master_admin_portal_prompt.md`.

## Goal

Build the SynaptiReach internal systems for templates, knowledge base, reports, integrations, and audit logs.

## Template Library

Support templates for:

- Email campaigns
- SMS campaigns
- Landing pages
- Workflows
- Funnels
- Lead magnets
- Content calendars
- Social posts
- GMB posts
- Review responses
- SEO metadata
- Proposals
- Reports
- Internal checklists
- Service workflows

Template metadata:

- Service type
- Industry
- Goal
- Tone
- Funnel stage
- Approval status
- Usage count
- Performance data if available
- Created by
- Last updated

## Knowledge Base

Support:

- SynaptiReach service playbooks
- Industry playbooks
- Campaign templates
- Workflow templates
- SEO checklists
- GMB checklists
- Branding checklists
- Sales scripts
- Outreach scripts
- Staff training
- Client onboarding guides
- Internal SOPs

## Reports

Support real-data reports for:

- Client reports
- Service reports
- Campaign reports
- Staff reports
- Revenue reports
- CRM health reports
- Prospect reports
- Monthly summaries

## Integrations Page

Show real integration data for:

- Connected integrations
- Integration status
- Sync status
- Last sync
- Failed syncs
- API connection health
- Required actions
- Permission state
- Webhook status if available

## Audit Logs

Track:

- Admin impersonation
- User changes
- CRM changes
- Campaign approvals
- Denials
- Revisions
- Staff actions
- Service order changes
- Workflow changes
- Billing-related changes
- Data exports
- Destructive actions
- Permission changes
- AI-generated actions
- Published campaign actions

## Requirements

- No fake logs.
- No fake templates.
- No fake reports.
- Use real data only.
- Add empty states where needed.
- Add filters and search.
- Audit logs should be read-only except for owner-level retention/export controls.
- Templates and knowledge base should be searchable.
- Staff access should be permission-limited.
- Every sensitive log view should respect permissions.

## Deliverable

Deliver template library, knowledge base, reporting center, integrations health center, and audit log system.
