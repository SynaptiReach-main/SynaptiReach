# Phase 5 - Global Approval and Denial System

Use the instructions from `00_master_admin_portal_prompt.md`.

## Goal

Build the SynaptiReach Global Approval and Denial System.

The approval system should handle all work that needs admin, staff, or client review.

## Approval Item Types

Support approval records for:

- Email campaign
- SMS campaign
- Landing page
- Workflow automation
- CRM setup
- Offer optimization
- Funnel copy
- Lead magnet
- A/B test
- Conversion audit
- Customer journey map
- Segmentation strategy
- Retargeting setup
- AI campaign strategy
- AI persona model
- AI funnel optimization
- Logo design
- Branding kit
- SEO optimization
- Local SEO
- Social media content
- Content calendar
- GMB optimization
- GMB monthly work
- AI-generated recommendation
- Staff-created deliverable
- Prospect outreach message
- Proposal

## Approval Actions

Support:

- Approve
- Deny
- Edit and approve
- Request revision
- Assign reviewer
- Send to client for approval
- Publish immediately
- Schedule for later
- Save as template
- Archive
- Escalate

## Approval Item Fields

Each item should include:

- Client
- Service type
- Created by
- Assigned reviewer
- Status
- Priority
- Due date
- Preview
- Internal notes
- Client-facing notes
- AI confidence score if available
- Risk/compliance warnings if available
- Revision history
- Approval history

## Views

Create:

- Global approval queue
- Approval detail page/modal
- My approvals
- Client approvals
- Staff submitted work
- AI-generated approvals
- Revision requests
- Denied items archive

## Requirements

- Use real records only.
- No fake approvals.
- Add filters by client, staff, type, status, priority, due date.
- Every approval/denial/revision must be logged.
- Admin can approve/deny anything.
- Staff can only approve/deny if permitted.
- Client approval should be supported where applicable.
- Add clean empty states.
- Add confirmation for publish/launch actions.

## Deliverable

Deliver a global approval queue, item detail view, approval actions, revision workflow, filtering, and audit logging.
