# Phase 5 - Admin Controls and User Settings UI

Build owner/admin settings for AI modes.

User/organization controls:
- Select default AI mode
- Configure BYOK provider settings
- Configure Local Connector
- Select local model
- Enable/disable fallback
- Set AI context limits
- Set staff AI permissions
- View AI usage/history if available

SynaptiReach admin controls:
- Enable/disable Local Connector globally
- Enable/disable BYOK globally
- View connector status by organization if permitted
- See AI mode distribution
- Review AI errors
- Disable unsafe connector usage
- Add feature flags

UI requirements:
- Clear explanations
- Warnings for advanced setup
- No misleading "connected" claims
- Production-safe states
- Mobile-friendly settings pages
